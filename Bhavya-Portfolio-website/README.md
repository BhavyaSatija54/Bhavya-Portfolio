# Bhavya Portfolio

A recruiter-focused portfolio for quantitative finance, risk analytics, investment banking and data projects.

## GitHub Pages
1. Upload this repository contents to `BhavyaSatija54/Bhavya-Portfolio`.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

Add your CV as `assets/BhavyaSatija_CV.pdf` and replace the LinkedIn placeholder in `index.html` with your profile URL.
