Data Engineering & Analytics Platforms

Equity Market Analytics Platform

A medallion pipeline over 503 S&P 500 equities and 20 years of daily data, built the way a data platform team actually ships one

Most portfolio dashboards start from a clean CSV. This project starts from raw Yahoo Finance data for the full S&P 500 and 20 years of history, and builds the actual pipeline underneath it: schema-enforced ingestion, a named and configurable data quality engine, feature engineering in PySpark, a rule-based market-scenario classifier, and a 5-page Power BI report sitting on top of a properly modelled gold layer.

02 / Architecture

Bronze, Silver, Gold, built with intent

The Bronze layer does schema enforcement, deduplication, and lineage tracking on the raw OHLCV and fundamentals data, partitioned by sector. Every layer runs a purpose-built data quality engine before writing, checking null rates, OHLC consistency, and a circuit breaker on any single-day price move above 50%, aborting the run rather than silently propagating bad data downstream. The Silver layer cleans and conforms that data, calculating returns and running the full feature engineering pass, filtering to instruments with at least 252 trading days of liquidity so a partial-year listing does not distort a rolling calculation.

The Gold layer is where the pipeline earns the word production-grade rather than analysis script. It is business-aggregated and BI-optimised: a fact table at the date-by-ticker grain, partitioned by year and quarter specifically for DirectQuery pruning in Power BI, alongside pre-aggregated scenario-performance tables and proper dimension tables for date, ticker, and sector-scenario. That separation of a granular fact table from pre-aggregated marts is exactly the modelling discipline a BI team needs to keep a report fast as the underlying data grows.

03 / Data Quality Framework

Checks that actually abort a bad run

CheckThresholdAction
Null rate per column> 1%Abort (strict mode)
OHLC consistencyhigh ≥ close ≥ lowAbort on failure
Price move circuit breaker> 50% one-day moveWarn
Duplicate (ticker, date)any occurrenceAbort
Data freshness> 48 hours staleWarn, log only

Quality scores from 0 to 100 are logged as structured JSON at every stage, designed to feed a monitoring stack like ELK or Datadog rather than sitting in a notebook cell no one revisits.

04 / Scenario Engine

A rule-based market regime classifier

RegimePriorityTrigger
Bear1S&P 500 drawdown ≤ −20%, VIX ≥ 30
Volatile2VIX ≥ 25, realised volatility ≥ 22%
Bull3Index near highs, VIX ≤ 18, momentum > 3%
Recovery4Momentum turning positive after a drawdown
Normal5, defaultNone of the above

Priority-resolved and defined in a YAML config rather than hard-coded, so a portfolio manager can adjust what counts as a bear market without touching the pipeline code, a small design choice that matters a great deal for how usable a tool actually is by non-engineers.

05 / What This Demonstrates

The difference between a dashboard and a data platform

A dashboard that reads a static CSV is a visualisation exercise. A pipeline that ingests raw data at scale, enforces its own quality gates, engineers features in a distributed compute engine, and models a gold layer specifically for BI performance is a data engineering deliverable, and it is judged on runtime, idempotency, and failure handling as much as on how the final chart looks. That is the standard this platform is built to.
